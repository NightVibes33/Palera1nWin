# Onboarding v2

The first-run guide and in-page help match the four-action downgrade interface:

1. Start Downgrade
2. Test DFU → Pwned/Pongo
3. Boot Device
4. Import Boot Profile

Start Downgrade is the normal path and performs device detection, IPSW inspection, and the non-destructive hardware test automatically when needed. Test DFU → Pwned/Pongo remains an optional non-destructive diagnostic. Boot Device and Import Boot Profile are post-downgrade actions.

The guide uses explicit high-contrast dark surfaces and text resources. Existing onboarding completion state is migrated once to content version 2 so users see the updated instructions.
